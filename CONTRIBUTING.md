# Contributing to IITS Helm Charts

Thank you for participating in the IITS Helm Chart development. Every contribution matters!

## Code of Conduct

By participating in this project, you agree to maintain a respectful and inclusive environment. Please be kind and constructive in all interactions.

## Versioning on charts

For each helm-chart in this repo, follow [Semantic Versioning 2.0.0](https://semver.org/) for the Chart Version

Examples:
```
2.0.0
1.0.0-alpha

1.4.5 -> 2.0.0 # used on a breaking change
1.4.5 -> 1.5.0 # used on a backward compatible feature
1.4.5 -> 1.4.6 # used for backward compatible bug fixes
```

The app-version is not regulated and can be used, when it has a positive benefit for the chart
