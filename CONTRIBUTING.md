# Contributing to IITS Helm Charts

## Versioning on charts
For each helm-chart in this repo, follow [Semantic Versioning 2.0.0](https://semver.org/)

Examples:
```
2.0.0
1.0.0-alpha

1.4.5 -> 2.0.0 # used on a breaking change
1.4.5 -> 1.5.0 # used on a backward compatible feature
1.4.5 -> 1.4.6 # used for backward compatible bug fixes
```
